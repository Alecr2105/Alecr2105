## 🚀 Featured projects

### [ambient-youtube-bot](https://github.com/Alecr2105/ambient-youtube-bot)
A bot that produces and publishes 3–4 hour lofi/ambient study videos to YouTube **every day, with no human intervention**, and feeds a 24/7 livestream.
- Resumable **state-machine pipeline** (SQLite), retries with backoff, and an automated audio/video **quality gate** (loudness, loops, black frames).
- Local AI for music and animated scenes (ACE-Step, Wan 2.2 via ComfyUI), GPU encoding with FFmpeg/NVENC.
- YouTube Data API v3 (OAuth2), FastAPI control panel, pytest test suite.
- 24/7 live stream on an **Oracle Cloud** VM under `systemd` using ~1% CPU.

`Python` `FastAPI` `SQLAlchemy` `Alembic` `pytest` `FFmpeg` `Oracle Cloud`

### [sql-data-warehouse-project](https://github.com/Alecr2105/sql-data-warehouse-project)
A **PostgreSQL data warehouse** using the Medallion architecture (Bronze → Silver → Gold) that integrates CRM and ERP sources into a star schema.
- Data-quality rules, audit tables, load monitoring and role-based access per layer.
- Automated ETL runs and backups with PowerShell.

`PostgreSQL` `PL/pgSQL` `SQL` `Data Modeling` `ETL`

### [cabina-express-mongo](https://github.com/Alecr2105/cabina-express-mongo)
REST API for a cultural center: rehearsal rooms, bands, musicians, bookings and equipment loans.
- MongoDB transactions, indexes designed for real queries, and a Postman collection for testing.

`Node.js` `Express` `MongoDB` `Mongoose` `REST`
